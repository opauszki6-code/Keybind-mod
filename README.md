# Keybind Slots (Fabric, MC 1.21.11)

- `í` gomb: megnyitja a slot menüt (Controls-ban átállítható)
- 3 slot, a nevük átírható a szövegmezőben
- **Mentés**: a jelenlegi összes keybind a slotba kerül
- **Betöltés**: a slot keybindjai életbe lépnek
- Mentés helye: `config/keybindslots.json`

Build: push GitHub-ra, az Actions lefut, a jar az Artifacts-ban van.
Release: `git tag v1.0.0 && git push --tags`
